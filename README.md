# kutsibalci.github.io

Hüseyin Kutsi Balcı'nın kişisel portfolyo sitesi: **[kutsibalci.github.io](https://kutsibalci.github.io)** · [English](https://kutsibalci.github.io/en/)

Seçkin projeler, deneyim, açık kaynak katkıları ve yetenekler. Türkçe ve İngilizce, koyu ve açık tema.

## Yapı

```
index.html      Türkçe sayfa
en/index.html   İngilizce sayfa
style.css       Stiller (iki dil ortak)
script.js       Galeri, proje penceresi, tema, kaydırma animasyonları
img/            Proje ekran görüntüleri (WebP), tanıtım videosu, logo
```

Çatı (framework) ve derleme adımı yok; düz HTML, CSS ve JavaScript. GitHub Pages `main` dalından yayınlar.

## Yerelde açmak

`index.html` dosyasını tarayıcıda açmak yeterli.
